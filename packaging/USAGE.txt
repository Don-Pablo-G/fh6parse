fh6parse — CNC tool list / min-Z report

Windows:  double-click fh6parse.exe  (or run from Command Prompt)
Linux:    ./fh6parse                 (or fh6parse --gui)

GUI
  fh6parse.exe
  fh6parse.exe --gui

Reports next to the NC file (A4 + 80 mm text and HTML)
  fh6parse.exe C:\path\program.nc
  ./fh6parse /path/program.nc

Output folder
  fh6parse.exe program.nc -o D:\reports

Header comments like (N10 - OP1) / (N20 - OP2) get a separate tool list each,
as if you changed M97 P# in main. Each list follows M97/M99 until M30.

Print: open the GUI, load the NC file, Print A4 or Print 80 mm.
  A4:     A4 paper, 100%, headers/footers off
  80 mm:  thermal printer, 80 mm paper, 100%, do not fit to A4

Raspberry Pi kiosk (portrait 600x800)
  Full wiring + OS + printer + update: packaging/LINUX-KIOSK.md
  sudo apt install python3-gpiozero python3-tk
  git clone, then:  sudo pip3 install -e . --break-system-packages
  python3 -m fh6parse --kiosk --config /etc/fh6parse-kiosk.ini
  Copy packaging/fh6parse-kiosk.ini.example to /etc/fh6parse-kiosk.ini
  Optional autostart: packaging/fh6parse-kiosk.service

  Update (git checkout only; plug in a keyboard)
    python3 -m fh6parse --version
    python3 -m fh6parse --update
    python3 -m fh6parse --version
  Pulls with --ff-only, skips pip unless pyproject.toml changed, restarts
  fh6parse-kiosk. Does not change /etc/fh6parse-kiosk.ini.
  After a pyproject change, re-run pip install -e '.[models]' if you use STEP
  views (--update installs the package without that extra).
  One-file ARM tarball cannot --update; copy a new tarball or use git.

  Encoder highlights a file. FULL prints the current 80 mm ticket; MIN prints
  the short ticket (T, description, min Z, warnings per operation).
  After 60 seconds idle the screen goes black. Rotary encoder, USB insert,
  keyboard, or mouse wakes it. GPIO print buttons while asleep are ignored.

  Keyboard/mouse (troubleshooting, hot-plug OK): arrows, click, wheel, F, M.
  Escape leaves fullscreen, Escape again closes.

STEP models on the 80 mm ticket (kiosk, optional)
  Set model_roots in /etc/fh6parse-kiosk.ini (several folders, subfolders ok).
  pip install -e '.[models]'   (git checkout; not in the one-file Pi tarball)
  Matching starts at the NC name prefix. G-code rev must match the .stp rev.
  If the NC has no rev, the latest matching .stp is used.
  Two opposite isometrics are stacked at the top of FULL and MIN tickets.
  A square mark (■) appears next to the file when the bitmap is ready.
  Missing or still-rendering models never block print.
  Full matching table and NAS mount: packaging/LINUX-KIOSK.md §3.7
